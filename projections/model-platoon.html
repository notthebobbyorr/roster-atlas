Annual trust uses personal history when shrinking each annual skill measurement before its three-year blend. After-blend trust combines recent native skills first, then regresses that blend using older career evidence that excludes the recent three seasons. Skill estimates remain outcome-specific because each event equation has its own weights and predictors.
